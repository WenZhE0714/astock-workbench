# 冻结交易复盘工作区

入口为「量化研究 → 交易复盘」，或`/?view=strategy&strategy=replay`。本期覆盖P008兼容的VolumeForward日档：真实前瞻与历史演练分别列出，历史演练不会被记为前瞻观察日。普通回测若没有同格式的冻结行情输入，不会通过重新下载当前行情冒充原始证据。

## 六项能力

1. 点击交易记录定位股票与日期区间，图上分开标记信号、买入和卖出；点击标记所在日期可选择对应交易。显示股数、成交价、费用、盈亏及退出原因。
2. 新复盘视图使用锁定的Lightweight Charts 5.2.0，支持平移、缩放、十字线、成交量、MA20/60及价位草案线。图表模块按需加载。既有个股行情图和Go计算引擎保留。
3. 逐日回放支持播放、暂停、单步、日期滑条和速度选择。每一步请求所选封存日，不预先把最终交易、最终净值或未来K线送入回放视图。快速切换会取消旧请求并隐藏过期快照。
4. 日线、已完成周线、个股与沪深300的区间涨跌幅对照使用同一截止日；日线可视区间向两张对照图同步，十字线按已存在日期对齐。周线使用现有的周五边界和首周排除规则，基准曲线只使用双方共有的日期并以观察起点之后首个共有收盘归零。
5. 股票池可按名称/代码、自选、当前持仓、待执行、已有平仓和量比达标的待执行信号筛选。加入自选复用现有自选接口和已有分组；命名筛选可保存、恢复和删除。
6. 提供交易复盘、单图专注及命名布局，可切换周线、基准、均线、标记和明细。图上选价后创建提醒草案，编辑方向、价格和有效期，明确确认后才启用本页提醒。

## 数据与回放边界

`GET /api/replay/catalog`只公开配置的来源、股票池和封存日期，不接受客户端文件路径。`GET /api/replay/day`要求来源ID、合法日期、股票和配置指纹；先校验源研究与整个日档哈希链，再读取所选日档。禁止POST，配置变化、损坏或晚于截止日的行情、信号、成交、净值均拒绝返回。

右侧/下方的形态依据、周线、基准、持仓与收益都来自所选日档。回放时隐藏主界面自选实时价格及实时研究助手，停用本页实时提醒检查并隐藏其记录。退出回放是显式操作，不会自动跳到最新行情。

当前八种形态解释由现有算法在冻结日K上重算；交易事实及P008规则仍以原日档为准。形态算法日后升级不会改写旧成交，但可能改变复盘解释，应结合日档指纹和版本辨识。日K回放不等于分钟级撮合，不能据此判断涨跌停排队或真实成交概率。

## 本页提醒

提醒存储在当前浏览器的localStorage中，仅在交易复盘页面打开且不处于回放时，每10秒检查当前报价。它不属于后台常驻提醒，也不发送系统通知，不连接券商。关闭页面后不继续监控。使用90秒以内、非未来时间戳的有效报价判断「达到或高于/低于」，到期或已经触发的规则不重复触发。单次规则可启停、删除；历史价位的来源日期和指纹保留在提醒中。

创建草案不会产生规则；「确认启用」才保存。回放状态下不能创建实时提醒，也不会用历史K线触发当前提醒。布局、筛选和提醒的本地存储失败都会显示错误。

## 配置与预览

现有`--volume-forward-dir`同时启用真实前瞻复盘来源。额外的`--replay-archive-dir`用于标记为「历史演练」的兼容归档；也可设置`ASTOCK_REPLAY_ARCHIVE_DIR`。`service install`支持透传该路径。读取归档不修改冻结配置、采集程序或账本。

```sh
go build -trimpath -o /path/to/astock ./cmd/astock
/path/to/astock web --listen 127.0.0.1:18769 \
  --volume-forward-dir /path/to/live-forward \
  --replay-archive-dir /path/to/historical/simulated-archive
```

前端开发可设置`ASTOCK_WEB_API=http://127.0.0.1:18769`后运行`npm run dev`，Vite会代理`/api`。需要现代Node.js，本机使用22.18.0。图表署名见页面「封存依据与图表署名」及`web/THIRD_PARTY_NOTICES.md`。

## 验证

- Go接口测试覆盖所选日档隔离、未来数据拒绝、路径及指纹校验、只读行为和损坏日档拒绝。
- JavaScript测试覆盖指标预热、成交/标记时间边界、基准共有日期、自选筛选和提醒报价时效。
- Playwright真实浏览器测试覆盖四组切换、交易定位、回放开始/单步/播放/暂停/快速定位、布局筛选持久化、自选写入、提醒明确确认及停用、导出、错误时隐藏旧快照。
- 桌面1440/900和移动390/320宽度检查溢出与截图；通过canvas像素检查确认图表不是空白。

历史测试来源为2026-07-16至2026-10-08的55个已封存演练日，仍保留原缺K造成的停止边界，没有补造剩余日期。
