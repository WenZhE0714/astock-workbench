# 实际量比下限的完整组合对照

## 固定协议

本轮来自上一轮稳定性诊断的单一假设：在原始 P008 趋势重返条件上，追加实际信号量比至少 1.5 倍。不是把技术参数中的量能基线从 1.2 改为 1.5。

- 原形态规则仍要求收盘重新站上 MA20、MA20 高于 MA60，并满足原价格位置和量能上下界。量能基线保持 1.2，对应本策略原上下界约为 0.9 至 3.5 倍。
- 量比定义为信号日成交量除以前 20 个股票交易日平均成交量，分母不含信号日。
- `Request.entry_volume_floor` 为追加的实际下限；默认 0 关闭，本实验固定比较 0 与 1.5，不扫描相邻阈值。当前仅接受趋势重返模式。
- 原条件先触发，再应用追加下限；等于 1.5 通过。未通过的原信号记录到 `volume_blocked_entries`，以后交易日的放量不会复活该信号。
- 买入仍为随后首个可成交开盘，一字板继续顺延；不根据成交日量能重新筛选。T+1、整手、开盘仓位预算、8% 止损、20% 止盈和 40 日最长持有期不变。
- 单股上限固定 10%，不加入双收盘确认、市场阶段过滤或利润回吐保护，股票池和费用保持原样。

## 运行

```sh
go run ./cmd/astock backtest volume-study \
  --output /path/to/new-volume-study \
  /path/to/frozen-position-study
```

输入为已完成且基线复现成功的冻结仓位研究目录，包含 `plan.json`、`result.json` 和 `cache/`。默认 `--cap 0.10`，须为源研究已有仓位。输出目录必须不存在。

命令先核对 SHA-256 并复制缓存，按原采集时间离线读取。完整复现基线的请求、成交、未平仓、费用及净值后，才运行追加量比下限的版本。四个验证窗及已见近期区间、两种规则、常规与双倍成本合计 20 次回测。

输出保留 `source-plan.json`、`source-result.json`、冻结缓存、固定实验协议、完整 `result.json` 和 `report.md`。不会自动晋级或修改影子账户，`promotion_allowed` 始终为 `false`。

## 归因

按股票和原始信号日期匹配原交易与过滤后的交易。只有被量比明确拒绝的原平仓才计为避开亏损或错过盈利；其他持仓路径导致的消失、新增入场分别列出。保留交易也重算实际现金、股数及费用，其盈亏不强行沿用原分组数值。

未平仓使用期末盯市盈亏。所有匹配差额必须与组合最终净值差在一分钱内相符。节省费用、避开亏损、错过盈利和保留赢家盈亏变化均已包含在净值差中，不能重复加总。

## 2026-10-19 结果

源实验 `AUTO-20261015T160220 / P008`，使用 2026-10-16 冻结的 175 个文件。F01 至 F04 覆盖 2022-07-16 至 2026-07-15；2026-07-16 至 2026-10-15 仍为已见诊断区间。

| 指标 | 原入场 | 追加实际量比至少1.5倍 |
|---|---:|---:|
| 四窗平均收益 | +8.0002% | +6.5259% |
| 最差回撤幅度 | 9.4965% | 4.7452% |
| 常规成本盈利窗口 | 3/4 | 4/4 |
| 双倍成本盈利窗口 | 2/4 | 4/4 |
| 双倍成本平均收益 | +6.6308% | +6.1071% |
| 平仓交易 | 228 | 76 |
| 各窗平均持仓比例的均值 | 15.16% | 6.26% |
| 已见近期区间收益 | -1.9145% | -1.1834% |

过滤版通过原离线常规及双倍成本检查。F02 从 -5.4129% 改善到 +0.9500%，双倍成本也为 +0.6281%；F04 从 +31.6937% 降至 +10.8238%。因此改善体现为较低暴露、回撤及更一致的窗口结果，并非平均收益全面提高。

四窗中，追加门槛拒绝了 110 笔原亏损，原亏损合计 412,038.38 元；同时错过 42 笔原盈利，原盈利合计 458,754.33 元。27 笔原大赢家仅保留 14 笔入场，原大赢家组盈亏减少 352,411.35 元。常规费用减少 18,215.96 元。金额是各独立起始窗口的归因合计，不是连续账户收益。

本次没有新增或其他原因消失的入场，保留的交易仍为原高量比分组中的信号。但完整资金路径使结果不同于简单提取原分组：例如 F04 原高量比分组贡献约 119,613.44 元，完整组合仅盈利约 108,238.11 元。

近期只剩江西铜业和初灵信息两笔，均亏损；原唯一赢家有研新材的 +28,674.36 元被门槛排除，同时避开五笔原亏损共 35,985.23 元。近期净值改善 7,310.87 元，仍然没有转盈。不能宣称已解决影子账户亏损。

## 决策与后续

保留为待验证候选，不直接替换现有影子策略。门槛由已见分组结果选择，四窗通过不等于未见样本有效；静态股票池、日K、不复权价格、历史固定费率及期末清算限制仍在。

下一步应冻结 1.5 倍规则与现有费用假设，进行与原策略隔离的前瞻影子对照。观察新交易的净收益、回撤、持仓暴露、错过赢家以及成交数量，累计预先约定的样本后再评估。不要把当前已见近期区间重新命名为最终留出，也不要马上继续优化相邻量比阈值。

## 验证

全仓 Go 测试、`go vet` 和差异检查通过。边界测试覆盖等于门槛、原上界保持、未来量能隔离、被拒信号不复活、一字板顺延、T+1、默认关闭及固定单变量对照。

独立 Node 脚本重新计算原形态、量能上下界及所有应拒信号，核对 20 次回测、628 笔平仓、8 个未平仓记录、322 条拒绝事件和 4,112 个净值点；同时重算费用、开盘预算、每日现金、净值差及大赢家归因。数量包含两个规则与两个成本场景。
