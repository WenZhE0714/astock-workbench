# 板块资金工作台

入口为“板块行情”或 `/?view=boards`。工作台包含六项相互衔接的能力：

1. 板块横截面支持榜单和资金气泡。横轴为涨跌幅，纵轴为主力净流入，气泡大小按净额绝对值平方根缩放；缺失数值不绘制。按名称、资金方向和数值排序筛选。
2. 服务端按分钟保存板块观察快照。日期、时间轴、播放/暂停和“实时”控制回放；最新视图轮询仅追加新增分钟。关闭浏览器仍采集，重启继续读取归档。
3. 资金趋势包含本地盘中累计净额和供应商日线资金。日线展示3/5个有数据交易日累计与连续正净额记录数，不把缺失日当作零；当天15:00前排除未完成日线。回放视图的日线截止到所选日期前一日。
4. 盘中盯盘、持仓风控、收盘复盘三个预设可切换。布局编辑可调整模块顺序、全宽/半宽与可见性，可保存最多12个个人预设。设置保存在当前浏览器的 `astock.board-workbench.v1`，清除浏览器存储后会丢失。
5. 选择板块联动候选与模拟持仓，选择股票更新个股行情、信号理由和账户持仓，可直接打开完整个股视图。行业按名称匹配，兼容末尾Ⅰ/Ⅱ/Ⅲ分类标记；无法匹配的行业不猜测归属。
6. “监控中心 / Mac 通知”保存提醒后的已读、已处理、备注、重点跟踪与当天静音状态。可点击通知直接定位原事件，处理不会修改策略分数或原始成交记录。

## 数据边界

盘中快照使用本地观察时间，不声称是供应商逐笔时间。采集限连续交易时段及15:00后5分钟的收盘窗口；交易日历未覆盖时须有两分钟内的当日有效上证指数报价确认。请求失败、旧缓存回退、跨交易时段完成的请求均不会生成新的盘中记录。每分钟文件首次发布后不可覆盖，历史缺采不补写。新安装在首次交易时段采集前没有可回放记录。

板块榜单源失败时，页面优先展示最近已保存的快照并标记“保留快照”；尚无归档时明确显示无数据。日线资金源与榜单源独立，一路成功不代表另一路也可用。

快照同时保留当时可用的候选摘要与模拟持仓，分别保留自身时间。回放不请求当前个股报价和成份股来填补历史空白。当前页面的成份股和日线资金来自独立请求；日线资金是当前供应商历史，不等于当时已留存证据。供应商数据不可用时显示错误，不生成示例行情。

## 存储与接口

- 快照：`$XDG_DATA_HOME/astock-workbench/board-snapshots/YYYY-MM-DD/HHMM.json`，默认位于 `~/.local/share`。
- `GET /api/board-snapshots?date=YYYY-MM-DD` 返回已有日期及所选日快照；`after=HHMM` 只返回后续分钟。
- `GET /api/board-daily-flows?code=BK0475&through=YYYY-MM-DD` 读取最多60条日线资金，缓存10分钟，优先直连东方财富。`ASTOCK_BOARD_DAILY_FLOW_URL` 可用于兼容接口或测试。
- `GET /api/native-notifications` 返回发送记录、处理记录和重点跟踪设置。
- `POST /api/native-notifications` 支持 `read`、`handle`、`note`、`follow`、`unfollow`、`mute`、`unmute`。处理动作使用 `id`，跟踪/静音使用 `symbol`，备注最多500字。
- 处理状态保存在 `notifications/reviews.json`，原始发送记录仍在 `notifications/mac.json`；当天静音在上海时区次日零点结束。

测试数据只用于隔离的 `TestBoardWorkbenchBrowserFixture`，不会写入用户行情或账户目录。
