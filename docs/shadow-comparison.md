# 多日对照评估

进入“影子账户 → 多日对照”，按日期范围查看六个冻结对照账户的收益曲线、同组基线差额、收盘回撤、平仓批次、胜率和费用。选择账户行的曲线按钮可切换明细，打开当前账本后返回会保留日期范围。下载按钮导出同一范围的JSON报告。

## 计算口径

- 起点累计收益：所选范围内最后一个有效封存时点的权益相对冻结初始资金的收益率。权益时点单独列示，不以今天的余额替换历史权益。
- 较基线：同一冻结组、同一起点且权益时点相同的两个账户的累计收益率之差，以百分点计。原五个历史账户不参与新对照组的基线比较。
- 区间收盘回撤：有效收盘权益相对区间内运行峰值的最大跌幅。范围包含对照首个交易日时，以冻结初始资金作为起始峰值；其他范围从首个选中收盘点开始。不包含盘中回撤。
- 回撤至少需要两个封存日，并要求所选范围的交易日日历覆盖完整、没有缺失或不可用的应有收盘快照；否则显示 `--`。一天收益为0不等于已经观察到可靠的风险水平。
- 交易与费用：按当前校正版账本的日期过滤，统计到该账户最后有效权益时点。平仓批次按退出记录计数，并非独立证券数；没有平仓时胜率显示 `--`。

## 数据与缺口

只使用通过指纹校验、已封存、估值完整、与当前账本修订及冻结配置一致的权益快照。未封存、损坏、配置偏移和过期修订会显示为空点，曲线不连接穿过这些空点。没有足够数据时暂停回撤计算，不补造历史权益。

交易日日历只读取已有的沪深300日K缓存；页面请求不拉取新行情。缓存没有覆盖整个选择范围时提示日历覆盖不足，无法认定完全缺档的交易日，也不输出完整区间回撤。当天15:30之前不要求当天收盘快照，对照起点在当日收盘之后时，从后续交易日开始统计。

“暂无平仓样本”“观察天数不足”“持续观察中”只是样本状态，不代表策略有效性结论。应同时积累交易日与有效成交数量，再比较收益、费用和尾部风险。

## 接口

`GET /api/strategy/shadow-comparison?start=YYYY-MM-DD&end=YYYY-MM-DD` 返回六个对照的序列与统计。默认从冻结起点所在日期到今天；未来日期、反向区间和超过366天的范围返回400。`download=1` 导出JSON。接口只读，不触发交易、不写入快照。
