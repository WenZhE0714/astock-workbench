# 冻结研究的逐笔亏损诊断

`backtest trade-review` 从已完成、基线复现成功的市场过滤研究读取未过滤基线，分析各验证窗口和近期诊断区间的正常成本成交，不修改策略或重新撮合交易。

```sh
go run ./cmd/astock backtest trade-review \
  --output /path/to/new-trade-review \
  /path/to/completed-regime-study
```

输出目录必须不存在。原输入文件先按SHA-256核验后复制，历史缓存按原冻结时点读取，全程离线。信号收盘、入场开盘、退出信号收盘和实际退出价均与冻结日K校验；不一致时停止诊断。

## 盈亏拆解

逐笔净盈亏拆为：从原始买入价持有至退出信号收盘的价格盈亏，加上退出信号收盘至实际卖出价的价格变化，减去双边滑点和费用。该恒等式用于归因，并不说明可以在退出信号收盘价直接卖出。

“退出信号后价格变化”可能含隔夜跳空、假期或不可成交日的延迟。报告同时给出交易日间隔和自然日间隔，不能把假期天数当作策略延迟。

## 浮盈口径

- 持仓路径只包含买入日至实际卖出之前的收盘。若期末按收盘强制清仓，则包含该收盘；普通次日开盘卖出不使用卖出日后续高低价或收盘价。
- 收盘净浮盈按原费用和滑点估算，买入当天明确标记T+1锁定。日K最高价不等于可执行的卖出价格。
- “首次浮盈收盘后下一开盘”假定在首次净浮盈收盘发出卖出信号，沿用次日开盘、T+1和一字板不可成交规则。这是逐笔事后诊断，不是已经验证的退出策略。
- 每个亏损交易按收盘路径分为：持有期未曾净浮盈、仅买入当日净浮盈、后续交易日曾净浮盈。它们与高开分组、退出原因是不同观察维度，不能跨维度重复加总亏损。

## 产物

`source-plan.json`、`source-result.json`及`cache/`保存原输入；`result.json`保存逐笔路径和统计，`report.md`汇总各窗口及近期逐笔明细。发生错误时保存不完整结果与`error.json`，不能把部分数据当作完整结论。

诊断用于选择下一项待检验假设。任何新规则仍需在全组合中同时考虑错过的盈利、现金路径、交易成本和未见数据，不能把亏损交易的理论改善简单相加当作新策略收益。
