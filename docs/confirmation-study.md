# 双收盘确认实验

## 固定协议

本轮只比较 P008 趋势重返策略的单收盘基线与双收盘确认。单股仓位上限 10%，MA20/60、量能基线 1.2、止损 8%、止盈 20%、最长持有 40 日，股票池与成本保持原样，不叠加市场阶段过滤。

1. 原始信号在 T 日收盘出现，原始量能和价格距离条件保持不变。
2. 双确认版本只检查该股票下一交易日收盘是否满足 `close > MA20 > MA60`。不重复要求量能、重新穿越或距离上限。
3. 确认通过后，最早于随后开盘成交。确认失败即作废；期末尚无确认日则记为未完成。
4. 一字板继续顺延，T+1、整手数量、开盘资金预算及所有退出规则保持原样。
5. `entry_signal.date` 保留 T 日；`entry_signal.confirmation` 另存确认日期、价格和均线。`entry_confirmations` 同时记录通过、拒绝和期末未完成的事件。

`Request.entry_confirmation` 默认空，原策略行为不变；`reclaim-two-close` 只接受 `trend-reclaim` 模式。该字段不开放自动晋级或影子账户切换。

## 运行

```sh
go run ./cmd/astock backtest confirmation-study \
  --output /path/to/new-confirmation-study \
  /path/to/frozen-position-study
```

输入为已完成且原基线已复现的仓位研究目录，含 `plan.json`、`result.json` 和 `cache/`。默认 `--cap 0.10`，必须是输入研究中已有的仓位。输出目录必须不存在；输入文件先按 SHA-256 核验，再复制到新目录，离线读取时间固定为原研究采集时间。

实验先重放全部基线的常规与双倍成本，比较请求、成交、持仓、净值及覆盖情况；出现实质差异立即停止。空持仓数组在 JSON 往返中的省略视为等价。然后运行双确认版本。四个验证窗口及已见近期区间共 20 次回测，报告保留原检查门槛，`promotion_allowed` 始终为 `false`。

## 机会归因

以“股票代码 + 原始信号日期”匹配已平仓及未平仓记录：

- 确认拒绝的基线亏损或盈利，分别计入避开亏损和错过盈利。
- 同一信号延迟成交后，记录实际盈亏差，不能仅统计是否仍然买入。
- 因持仓路径变化消失的成交、因资金或期末未成交，以及新出现的成交单独列出。
- 大赢家固定定义为基线已平仓净收益率达到原止盈比例，本轮为 20%。保留其入场不等于保留盈利。
- 未平仓使用期末盯市浮盈亏；所有机会差额之和必须与组合最终净值差在一分钱内相符。

逐笔差额包含买价、退出时点及资金路径造成的数量变化，并非纯粹的价格延迟效应。各窗口独立以 100 万元起始，跨窗口金额合计只作归因汇总，不是连续账户收益。

## 2026-10-16 结果

冻结源：`AUTO-20261015T160220 / P008`，175 个输入文件。验证区间为 F01 至 F04：2022-07-16 至 2026-07-15；2026-07-16 至 2026-10-15 为已经观察过的诊断区间。

| 指标 | 单收盘基线 | 双收盘确认 |
|---|---:|---:|
| 四窗平均收益 | +8.0002% | +6.1166% |
| 最差回撤幅度 | 9.4965% | 12.1377% |
| 正收益窗口 | 3/4 | 2/4 |
| 平仓交易 | 228 | 162 |
| 双倍成本平均收益 | +6.6308% | +5.0833% |
| 常规成本检查 | 通过 | 未通过 |
| 双倍成本检查 | 未通过 | 未通过 |
| 已见近期区间收益 | -1.9145% | -2.9445% |

F02 从 -5.4129% 改善至 -2.3202%，但 F04 从 +31.6937% 降至 +22.7292%，F01 由小幅盈利转为亏损。四窗共拒绝 61 笔基线亏损（214,434.82 元），同时拒绝 6 笔盈利（26,498.41 元）；保留的原盈利交易合计少赚 238,414.23 元。27 笔原大赢家仍进入 26 笔，但这一组盈亏合计减少 182,277.38 元。

有研新材 2026-08-06 的信号说明了入场时点与退出规则的联动：基线 08-07 按原始开盘价 46 元买入，08-17 收盘触发 20% 止盈，08-18 开盘退出，净赚 28,674.36 元。双确认 08-10 才按 50 元买入，收盘未触及提高后的止盈价，09-01 跌破 MA20，09-02 退出，净亏 4,660.53 元。盘中最高价不能当作按现有收盘规则可兑现的止盈。

结论：不采用本轮双收盘确认，也不将它叠加到影子账户。减少交易和提高局部窗口表现不足以证明改进，基线本身也仍未通过双倍成本检查。下一轮可先诊断基线的可成交盈利回吐与退出效率，再决定是否预先固定一个退出端实验；不根据本轮结果连续追调参数。

验证包括全仓 `go test ./...`、`go vet ./...`、确认时序及基线兼容测试，以及独立 Node 脚本核验 20 次回测、806 笔平仓、480 条确认事件和 4,112 个净值点。独立核验覆盖原始数据指纹、确认均线、成交费用、T+1、仓位上限、每日现金与持仓价值。

局限：规则由已见亏损诊断提出，存在研究选择偏差；静态股票池存在幸存者偏差；使用不复权日 K、固定历史费率及期末强制平仓。结果是离线研究，不代表真实影子账户同期收益，也不是未见样本的正式晋级证据。
