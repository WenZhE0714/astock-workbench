# 固定仓位的市场阶段过滤对照

`backtest regime-study` 读取一次已完成且基线复现成功的仓位研究，固定其中的单股仓位、股票池、规则、费用及全部输入文件，仅比较“原规则”和“非熊市开仓”。

```sh
go run ./cmd/astock backtest regime-study \
  --output /path/to/new-regime-study --cap 0.10 \
  /path/to/completed-position-study
```

## 唯一策略变量

过滤组的 `entry_market_filter` 为 `non-bear`，基线为空。使用现有市场分类器：最近20个交易日收益不高于-5%、收盘不高于60日均线，且未先被分类为高波动时，判为熊市。高波动在本轮不额外禁止，避免同时更改两个市场约束。

过滤在开仓当天执行，只能使用该日之前已经收盘的基准日K。开仓信号仍按原规则生成，若实际尝试开仓时为熊市则取消该待买单，并记录信号日、尝试日、基准数据日和原因；不会在市场恢复时直接重放被取消的旧单。已有持仓的退出、止损、T+1及一字板规则不变。

缺少基准时研究返回错误；基准历史不足或缺少最近应有交易日时暂停该次开仓，记录为数据不足，不能将这种数据缺口当作过滤收益优势。

## 输入与可复现性

命令校验原仓位研究的 `plan.json`、`result.json` 和各缓存文件SHA-256，把完全一致的输入复制到新目录，不读取更新后的在线行情。缓存有效性按原冻结时点判断，因此不会因日历时间经过而让同一快照在复跑时过期。

原四个验证窗口和原近期区间都执行正常成本、双倍成本两次计算。正常成本与压力成本规则复用仓位研究。近期区间已被观察，仅作诊断，不能称为新最终留出；本工具始终不自动晋级，也不操作影子账户。

## 机会归因

通过“证券＋原入场信号日期”匹配基线和过滤组。明确被市场规则拦截、且未在过滤组入场的基线已平仓交易，分为避开的亏损和错过的盈利。不能匹配到基线成交的拦截只是开仓尝试，不算被避免的交易。

由于现金和仓位路径可能变化，归因金额不能与两组实际净值差重复相加。报告同时保留其他原因消失的入场、新增入场、实际净值差和日均持仓占权益比例，避免把更少交易误当作策略优势。

## 输出

- `plan.json`：本次固定仓位、两个过滤版本及信息时点规则。
- `source-plan.json`、`source-result.json`：原仓位研究配置及完整结果。
- `cache/`：通过指纹校验的同一份冻结输入。
- `result.json`：两组的交易、权益、拦截记录、检查结果和机会归因。
- `report.md`：正常与双倍成本的比较摘要。

观察窗口收益可能包含期末受T+1限制的未平仓浮盈。静态股票池、不复权价格、固定历史费率及日线撮合的限制与原研究一致。
