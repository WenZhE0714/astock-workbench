# 每日对照复盘与零交易原因

在“影子账户 → 每日复盘”查看所选日期、所选账户组的扫描、信号资格、实际成交、费用和已实现盈亏。可以切换“原账户 / 优化对照”，打开当前账本后返回仍保留复盘日期，也可以导出当日 JSON 报告。

## 三种证据

1. **扫描与资格复核**：只读取该日期的 `realtime-signals/YYYY-MM-DD.jsonl`，按账户规则复核入场资格。连续交易时段之外、对照起点之前、重复快照、无效信号和时间尚未到达的记录单独排除。同一证券在多次扫描中出现属于多次观测，不能当作独立股票或独立交易样本；页面同时显示证券数。
2. **实际执行记录**：从当前校正版账本筛选当天的订单、决策和退出记录。费用和已实现净盈亏不包括当前浮盈。执行未成交原因按决策及拒单记录汇总，同一执行事件可能有多条记录，不能与资格未通过观测数相加。
3. **当日权益快照**：从功能启用后实际运行留存的账本快照读取。盘中更新，收盘且持仓估值日期完整、账本校验通过后封存。未留存日期显示缺失，不用今天的权益推算历史权益。

资格复核直接使用影子引擎的入场资格判断，不改变交易规则。仓位、入场延伸上限、不加仓等后续执行约束由真实决策/拒单记录解释；资格通过不等于已经下单或一定成交。熊市抓妖即使雷达高分也会在资格阶段显示禁入原因。

已留存当日快照时使用其中的配置；当日账本可用时使用账本配置；更早日期没有配置快照时明确标为“按当前规则复核历史信号”。最后一种是诊断复核，不能宣称是当时的决策日志。

## 收益比较

- 当日已实现净盈亏：按退出日筛选的净盈亏，不等于包含浮盈的每日账户总收益。
- 较基线已实现差额：同一对照组、同一起点账户的当日已实现净盈亏之差，以元计。
- 累计收益率差：所选日期权益快照相对本组基线的累计收益率差，以百分点计。要求两边快照阶段一致、估值日期完整、校验通过且未落后于当前账本修订；当日规则与当前账本也须匹配冻结对照配置。
- 新旧账户累计收益不能直接混作同起点对照。没有快照或起点尚未到达时不显示比较值。

这里没有从累计已实现盈亏推算最大回撤，也不会把未平仓盈亏记作当日已实现收益。

## 接口与归档

`GET /api/strategy/shadow-daily?date=YYYY-MM-DD` 返回当日全部已配置账户的摘要、扫描来源状态、未交易原因及可选日期。省略日期默认上海时区今天，未来日期和非法日期返回400。`download=1` 导出相同数据。接口只读，不请求新行情、不触发交易或重算历史成交。

每日账本快照位于 `paper/daily-reviews/YYYY-MM-DD/`：

- `<profile>-live.json`：当日最新盘中/未完成快照。
- `<profile>-r<revision>.json`：通过校验的收盘快照，包含配置和内容 SHA-256，不覆盖已有同修订快照。
- 账本发生校正后可留存新的修订，旧快照仍保留；历史快照早于当前账本修订时，其比较值暂不用于展示。

自动调度和手动同步成功后采集当前日期快照，跳过其他日期或尚未到达的账本时点。读取页面不会补写历史权益。归档错误会进入自动任务错误信息，并显示在每日复盘页面。

扫描统计使用文件大小、修改时间和账户配置指纹缓存，文件追加后重新统计。读取范围固定为开始读取时的文件大小；未完成末行、不可解析行和未来时间记录都有提示，不当作完整数据。这个文件版本标识用于缓存失效，并非扫描档案的密码学签名。

## 验证范围

测试覆盖资格判断、重复快照、对照起点、未来记录及系统时钟回退、追加期间的有界读取、缺失与损坏档案、收盘封存和修订、历史日期隔离、只读查询、导出，以及桌面/移动端导航。真实账户的统计应以页面标出的档案范围和记录时点为准。
