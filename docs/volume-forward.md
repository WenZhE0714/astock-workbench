# P008量比前瞻对照

本实验承接2026-10-19的量比研究，固定比较P008原入场与追加实际信号量比至少1.5倍。历史研究的常规和双倍成本检查通过只代表候选值得继续观察，不等于正式晋级。

## 固定协议

- 两组分别以100万元、零持仓开始；单股上限10%，股票池沿用原14只股票。
- MA20/60、20日量能基线1.2、原量能上下界、8%止损、20%止盈、40个交易日最长持有期保持不变。量比的分母不含信号日。
- 两组另各计算双倍成本，费用及滑点全部乘2，共四条独立资金路径。
- 只产生冻结日期之后的新信号。首次收盘记录待执行信号，最早下一股票交易日开盘模拟成交，继续遵守整手、T+1和一字板顺延。
- 每日估值保留未平仓，不使用历史研究的期末强制平仓。
- 至少60个封存交易日且候选完成10笔平仓后再复核；仍要检查净收益为正、沪深300超额为正、回撤不超过10%、双倍成本收益为正。报告同时列出相对原规则净值差、平均持仓暴露、避开亏损与错失赢家。
- `promotion_allowed`始终为`false`。本实验没有修改原五个影子账户、六个优化对照、评分权重或研究Champion的入口。

## 执行和证据

这是逐日收盘封存的日线模拟，不是盘中撮合服务。一个交易日的完整日K可以判断当日是否一字板，再按开盘价模拟先前已封存的订单；因此实际成交概率、涨跌停排队与盘中流动性不在验证范围内。

每日15:30至19:00直接读取腾讯不复权日K，同一次采集为全部四组提供输入。`days/YYYY-MM-DD.json`原子保存原始输入、待执行信号、完整成交、持仓、现金、净值、费用、机会归因和检查结果。缺失换手率以JSON `null`封存，读取时恢复缺失状态，不当作0；必需OHLCV仍须通过有效性校验。每个日档包含配置指纹、前一日档指纹和自身指纹；`head.json`检测末端丢失。首日之前的日K只用于指标预热。

后续日档从已有封存数据加当日新K推进。旧OHLCV变化、缺失股票日K、与沪深300日历不齐、漏采交易日或程序指纹变化时停止推进并报告异常。不能事后补采漏掉的交易日并计入前瞻样本。停牌资料目前不完整，因此缺K时保守暂停整个实验；必要时另建实验，不改写旧证据。

新交易日到来时使用同一日线引擎回放已封存输入，核对过去净值、平仓和持仓入场未变化，才保存新结果。多个进程同时更新会被文件锁拒绝；重复更新已封存日期不重写日档。

## 命令

必须先编译并保留实验专用二进制；`init`将实际程序的SHA-256一起冻结，后续仓库更新不会改变本实验程序。

```sh
go build -trimpath -o /path/to/frozen/astock ./cmd/astock
/path/to/frozen/astock backtest volume-forward init \
  --source /path/to/completed-volume-study \
  --output /path/to/new-forward-directory
/path/to/frozen/astock backtest volume-forward preflight /path/to/forward-directory
/path/to/frozen/astock backtest volume-forward update /path/to/forward-directory
/path/to/frozen/astock backtest volume-forward status /path/to/forward-directory
/path/to/frozen/astock backtest volume-forward audit /path/to/forward-directory
```

`preflight`只预检当前行情和指标预热，不记为观察日。`status`和`audit`只读校验配置、源研究副本及全部日档哈希链；不重拉行情。`report.md`为最近一次有效封存的摘要，`status.json`为最近调度状态；发生错误时需结合两者阅读。

- LaunchAgent：`com.github.wenzhe.astock-workbench.volume-forward`。
- 调度：登录时运行并每300秒检查一次，只在允许时段下载；当天封存后仅校验已有档案。
- 日志：`~/Library/Logs/astock-workbench/volume-forward.out.log`和`volume-forward.err.log`。
- 独立XDG数据、配置和缓存目录；HTTP代理沿用`127.0.0.1:7897`。
