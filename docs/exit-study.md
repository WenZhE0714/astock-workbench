# 盈利回吐与退出效率实验

## 本轮协议

固定 `AUTO-20261015T160220 / P008`，单股仓位上限 10%，MA20/60、原量能条件、8% 止损、20% 止盈、40 日持有期、股票池及费用均不变。继续使用 2026-10-16 冻结的 175 个输入文件，不加入双收盘确认或市场过滤。

唯一候选为 `close-profit-half-giveback`：

1. 每个持仓自买入日起记录最高净收盘浮盈，净值口径扣除已付买入费用和假设按该收盘卖出的滑点及费用。
2. 峰值达到原止损幅度后激活保护。本轮为净浮盈 8%，不是盘中最高涨幅，也不是未扣费的涨幅。
3. 激活后，当前净收盘浮盈低于或等于峰值的一半时发出卖出信号。原止损、止盈、均线和最长持有期退出均优先；已有待成交卖单不被替换。
4. 最早下一可成交开盘执行，沿用 T+1、一字板顺延及期末清算规则。跳空仍可能导致亏损，不能承诺锁住峰值利润的一半。
5. 每次新建仓位独立记录峰值。双倍成本场景重新计算净浮盈和激活时点。

`Request.exit_protection` 默认为空，原行为保持不变。保护退出的 `exit_signal.profit_protection` 记录规则、激活门槛、峰值日期、峰值净浮盈、回吐门槛和当前净浮盈，供时序审核。

## 运行与输出

```sh
go run ./cmd/astock backtest exit-study \
  --output /path/to/new-exit-study \
  /path/to/frozen-position-study
```

输入是已完成且原基线复现成功的仓位研究目录，包含 `plan.json`、`result.json`、`cache/`。默认仓位为输入中已有的 10%，可用 `--cap` 指定已有仓位。输出目录必须不存在。

命令先核验 SHA-256 并复制冻结输入，按原采集时间离线读取。完整复现基线的请求、交易、未平仓、净值和数据覆盖后才运行候选。四个验证窗口和已见近期区间，各跑原规则/保护规则及常规/双倍成本，共 20 次组合回测。原门槛不变，`promotion_allowed` 始终为 `false`。

输出中的 `source-plan.json`、`source-result.json` 和 `cache/` 为原始证据；`plan.json` 固定规则；`result.json` 保存回测、诊断和机会匹配；`report.md` 为汇总。失败时保存不完整结果及错误，不标记完成。

## 两种归因

逐笔诊断固定基线买入价、日期和数量，只在原退出信号出现之前寻找保护触发。另计算“首次收盘净浮盈后下一可成交开盘卖出”作为诊断参照，不将其当作本轮组合候选。买入日浮盈可以产生次日信号，但不能当日兑现；普通开盘卖出之后的高低价和收盘不进入持仓诊断。

组合对照重新运行完整资金及持仓路径，按“股票 + 原始入场信号日期”匹配，单列新增和消失的入场，并包含期末未平仓浮盈亏。归因差额必须与最终组合净值差在一分钱内相符。原大赢家定义沿用基线已平仓净收益率至少达到 20%，保留入场不代表保留其全部利润。

两种差额不能相加。各窗口独立以 100 万元起始，跨窗金额合计也不是连续账户收益。

| 双倍成本检查 | 未通过 | 未通过 |

四窗的 160 笔亏损中，73 笔曾有收盘净浮盈，57 笔在首次浮盈后的下一可成交开盘仍盈利。但将所有符合条件的原交易改为首次浮盈即退，会在固定入场的诊断中合计少赚 268,121.41 元，说明大赢家被截短的代价不能忽略。

保护规则在常规成本验证窗触发 28 次退出，近期区间为 0 次。在组合归因中，原亏损组改善 66,139.75 元，原盈利组减少 200,163.63 元；27 笔原大赢家均保留了入场，但这一组的盈亏减少 195,060.88 元。费用、后续数量与未平仓影响均体现在最终净值差中。

固定原入场的案例：初灵信息原交易在 2024-10-08 退出，净赚 63,868.25 元。保护规则在 09-11 收盘触发，09-12 开盘提前退出，净赚 9,159.99 元，少赚 54,708.26 元。相反，英维克一笔原本净亏 3,825.49 元的交易可被改为净赚 7,215.03 元。规则有局部收益，但全样本代价更高。

结论：不采用该规则，不自动写入影子账户，也不在本轮继续搜索新的激活或回吐阈值。近期亏损没有改善，原策略的双倍成本门槛也仍未通过。下一步应先检查逐股、逐年收益集中度及原始入场信号的分组稳定性，判断亏损和盈利分别依赖哪些条件，再决定是否修改策略结构。

验证包括核心测试、全仓 Go 测试、`go vet`，以及独立 Node 核验：175 个文件指纹、20 次回测、944 笔平仓、56 个保护退出事件、472 条基线诊断记录、4,112 个每日净值点。独立脚本重算最早退出日期、净浮盈峰值、原规则优先级、逐笔探测、成交费用、每日资金与仓位上限。

局限仍包括静态池幸存者偏差、不复权日 K、固定历史费率、期末强制清算及规则来自已见样本的选择偏差。2026-07-16 至 2026-10-15 是已见诊断区间，不是新的最终留出。本报告不代表真实影子账户的同期收益。
